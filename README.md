# Atlas do Movimento

Biblioteca técnica de aparelhos, exercícios e biomecânica.

A primeira coleção reúne dez aparelhos Matrix confirmados por modelo e documentação técnica. Cada ficha reúne identificação, imagem do equipamento extraída do manual, função muscular, regulagem, execução, biomecânica, erros frequentes, documentação do fabricante e vídeos de referência.

O projeto será organizado em três núcleos: aparelhos utilizados na academia, exercícios caseiros com acessórios e peso corporal, e calistenia com barra. Nesta etapa, o site publica somente o catálogo do primeiro núcleo; as séries serão montadas depois que os 14–15 aparelhos estiverem catalogados.
